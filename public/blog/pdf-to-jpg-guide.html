How to Convert PDF to JPG (Each Page as an Image)

PDFs are perfect for documents, but sometimes you need a plain image. Maybe you want to share a single page on WhatsApp, drop a page into a presentation slide, or post it on social media where PDFs are not supported. Converting to JPG gives you an image that opens anywhere.

How to convert PDF to JPG for free

Open the PDF to JPG tool and:

  1. Drag your PDF in or click to browse.
  2. Choose JPG, PNG or WebP, requested DPI, quality and an optional page range.
  3. Download one page directly, or select several rendered pages for a ZIP.
Tip: Need one page? Choose Custom Range and enter one page number, then download that image directly.

Quality and file size

Higher requested DPI creates more pixels and usually larger files. Very large pages can be capped to browser-safe canvas dimensions; check the actual first-page pixels and DPI shown in the result.

Use caseWhat to expect
WhatsApp / social sharingStandard resolution — small, fast to send
Slides / presentationsHigher resolution for a clear projection
Printing a pageHighest resolution for crisp output
Note: A JPG of a text page is an image — the text inside is no longer selectable. If you need editable text, use OCR or PDF to Word instead.

Related tools

Going the other way — images into a PDF? Use Image to PDF. If the exported image is too large, use Compress & Resize Image after checking the required dimensions.
