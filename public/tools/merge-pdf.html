What Does the Merge PDF Tool Do?

PDFdukan's Merge PDF tool lets you combine PDF files online free: add two or more unlocked PDFs, pick the pages you need from each one, set the file order, and download one merged PDF. The merge runs in your browser, so your files are not uploaded to our server.

How Do I Combine PDF Files?

Combining PDFs takes four steps:

  1. Add your PDFs. Tap Choose PDFs or drop two or more files. Each file appears as a card.
  2. Set the file order. Drag a card by its ⠿ handle, use ↑ and ↓, or sort by name or size.
  3. Pick the pages. Tap page numbers to leave pages out, or use the All, None or Range… buttons.
  4. Merge and save. Tap Merge PDFs, check the page count, then tap Download Merged PDF and name the file.

What Can You Control Before Merging?

Four controls shape the final document:

Page picker

Drop blank pages or covers. Range… accepts entries like 1-3, 5, 7-10.

File order

The top card becomes the first pages of the merged PDF.

Sort buttons

Name A → Z lines up files like part-1 and part-2 in one tap.

Remove

The ✕ button drops a wrong file and keeps the rest.

What Does the Merged PDF Keep?

Our test merges with links, bookmarks and form fields gave this result:

KeptPage content, selectable text, image resolution, web links
Not keptBookmarks and working fill-in form fields
Not acceptedPassword-locked or damaged PDFs, and non-PDF files
Number of filesTwo or more; your device's memory sets the practical limit

When Do People Merge PDFs?

Most merges serve a form that takes one file:

  • A resume and cover letter for a job portal.
  • W-2s, 1099s and receipts at tax time.
  • Pay stubs, bank statements and an ID for a rental application.
  • Scanned chapters for one class submission.

How Do I Get a Clean Merged File?

Fill in any forms before you merge, because form fields stop working afterwards. Pages keep their original order inside each file, so to mix pages between files, merge first and then use Rotate, Reorder & Delete PDF Pages.

File too big for a portal? Shrink it with Compress PDF. For photos, use Image to PDF first.

Are My PDFs Uploaded?

No. The Merge PDF tool joins your files with code running in your browser, so they are not sent to a PDFdukan server. The page still loads site files, analytics and ads.
