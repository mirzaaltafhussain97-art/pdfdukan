PDF Restriction Compatibility Check

Check whether the current browser PDF library can re-save your file. It cannot decrypt encrypted PDFs, remove an unknown password, or guarantee removal of permission restrictions.

⚠️ Limitation: Encrypted and password-protected PDFs are not supported. A successful re-save is not proof that every permission restriction was removed.

Remove Compatible PDF Owner Restrictions

This page uses PDF-lib to test whether a PDF can be loaded and written again in the browser. PDF-lib's official documentation states that encrypted documents are not supported. Re-saving an ordinary unencrypted PDF is not the same as decrypting it or reliably removing its permission controls.

If a PDF asks for a password, reports encryption, contains a digital signature, or has permissions you must preserve, use the document owner's password and a PDF application that explicitly supports that encryption method. Do not rely on a compatibility re-save for legal, signed or archival records.

Important: only process documents you own or are authorised to modify. This tool does not bypass unknown passwords and now fails closed on encrypted input instead of using PDF-lib's discouraged ignoreEncryption option.

What This Tool Can Remove

🖨️ Printing

A successful re-save does not guarantee that every viewer's printing permission will change.

📋 Copying

Text selection depends on the PDF content and viewer, not only a permission flag.

✏️ Editing

Forms, signatures and annotations can change when a PDF is rewritten; verify them independently.

🔒 Privacy Kept

Everything runs locally in your browser. Your bank statements and private documents never touch a server.

How to Unlock a PDF in 3 Steps

  1. Upload your PDF — Click the upload area or drag and drop the restricted PDF.
  2. Automatic unlocking — The tool rebuilds the PDF without the owner restrictions. This takes a few seconds.
  3. Download the unlocked file — Open it in any PDF reader: printing, copying, and editing now work normally.

Common Situations Where You Need This

  • Bank statements: Many banks send statements with print/copy restrictions. Unlock them to print for loan applications or visa files.
  • Official forms: Some downloadable government and university forms block printing — unlock them to print and fill by hand.
  • Reports you authored: If you lost the original file and only have a restricted PDF export of your own work, unlocking lets you reuse your content.
  • Reference material: Copy quotations and citations from documents you have the right to use academically.
