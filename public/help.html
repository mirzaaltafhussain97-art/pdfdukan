📷 Document Scanner

CamMaster first attempts an ONNX document-corner model in the browser. If the model cannot load or does not return a reliable quadrilateral, an OpenCV.js multi-method fallback looks for a likely document boundary. Automatic detection can be wrong, so inspect and adjust all four crop handles before applying the crop.
When you photograph a document from an angle, it appears tilted. Perspective warp takes the 4 corner points you've set and mathematically transforms the image so the document appears as if photographed straight from directly above — flat, square, and correctly proportioned. This is also called "deskewing" or "perspective correction."
  • Original — keeps the cropped pixels unchanged
  • Enhance — adjusts illumination, levels and contrast
  • Magic Pro — applies stronger shadow and readability processing with a browser fallback
  • Lighten — brightens darker page pixels
  • No Shadow — reduces uneven page illumination
  • B&W — creates high-contrast black-and-white output
  • B&W Soft — keeps more grey transitions than B&W
  • Grayscale — removes colour
  • Eco — produces a lighter output intended to use less ink

Compare every result with the source; a filter can improve one document and damage detail in another.

Yes! After processing your first page through the crop and filter steps, you'll arrive at the Pages screen. From there, you can click "Add More" to upload additional images or PDFs. All pages can be reordered by dragging. When you're ready, go to the Export screen to download as a single multi-page PDF.
Edge detection works best when there is good contrast between the document and the background. Try: (1) Place the document on a dark, non-reflective surface. (2) Ensure good, even lighting. (3) If detection still fails, manually drag the corner handles to the document's corners and click "Apply Crop" manually.

📄 PDF Tools

In the Merge PDF tool, after you add your PDF files, each file appears as a card with numbered page checkboxes. Click individual page numbers to toggle them (highlighted = selected, grey = excluded). Use the All / None buttons for quick selection, or click Range… to type a range like "1-3, 5, 8-10". Only checked pages will be included in the merged output.
In the Split PDF tool, upload your PDF and select the Visual Split mode. Your PDF pages will appear as thumbnails. Between each pair of pages, you'll see a ✂️ split here divider. Click a divider to activate it (it turns red). You can activate multiple dividers to create multiple output parts. Then click "Split PDF" to download a ZIP containing all the parts.
Image to PDF accepts JPG, JPEG, PNG, and WEBP files. You can add multiple images at once and they'll each become a page in the PDF. The page size, orientation, margin, and JPEG quality are all configurable before generating.
OCR accuracy depends on the source. Use a sharp, upright image with readable character detail, select the correct language or listed mixed mode, and match the page layout. Start with Original pixels; try Document contrast for faded paper, but compare both results because enhancement does not improve every image. For important names, dates and numbers, check the complete output against the source.
Yes. Use the separate Compress PDF tool. Its presets rasterize PDF pages at selected dimensions and image quality, so selectable text, forms, links, signatures or vector detail may change. Keep the original and verify readability, page count and important document features before using the compressed copy.
There is no single guaranteed maximum because available memory, browser limits, page count, image dimensions and the selected tool all matter. If a large file is slow or the browser reports a memory error, try fewer pages, smaller source images or separate batches. Keep the original until the output has been checked.

🔒 Privacy & Security

CamMaster's core crop, filter and export workflow runs in your browser. Optional connected actions, such as saving an output to Google Drive, communicate with that provider only when selected. Analytics and normal page requests are separate from document processing; see the Privacy Policy.
Basic tools may store preferences and recent document names in browser storage. Core local-processing tools do not intentionally send selected file contents to PDFdukan servers. Accounts, contact messages, analytics, third-party library downloads and optional Google Drive saves have separate data flows described in the Privacy Policy.
Go to your browser's privacy settings to remove all saved recent documents. To clear all CamMaster data from your browser, clear the localStorage for pdfdukan.com in your browser's developer tools, or use your browser's "Clear Site Data" option in site settings.
No website can give a blanket safety guarantee for every device or document. CamMaster core crop, filter and export processing runs in the browser, but ordinary page requests, optional Drive saves, accounts and analytics are separate. Use a trusted, updated device, inspect the destination, and avoid processing material you are not authorised to handle.

👤 Account & Sign-In

No. The listed basic scanner and document tools can be used without an account. Sign-in is optional and is used for account features and connecting Google Drive when you choose to save a selected output there.
Google Sign-In can authenticate your PDFdukan account and request the drive.file permission used to create or access files selected through the app. When Drive is connected, you can save a chosen output to the PDFdukan folder in your Google Drive. It does not make core scanner processing server-side.
Click your name or the "Sign In" button in the top-right corner of any page. A dialog will appear asking if you'd like to sign out. Confirm to sign out and clear your account session from this device.
