## Claims that need modern caveats

- Backlinks are important, but calling them the universal “number one ranking factor” is too absolute.
- A fixed 300–400-word threshold does not reliably define thin content; usefulness, uniqueness, intent satisfaction, and site context matter.
- Title/meta character counts are display guidelines, not guaranteed ranking limits; pixel width and query-dependent rewriting matter.
- Nofollow does not have a reliable public “50–60% value” formula.
- FAQ rich results are restricted and not generally available to every ordinary site; valid FAQ markup does not guarantee display.
- Schema can improve machine understanding and rich-result eligibility, but does not guarantee ranking or a rich result.
- robots.txt controls crawling, not reliable removal from Google’s index; index control needs the appropriate accessible directive/status/canonical strategy.
- Buying links, PBNs, link farms, and scaled manipulative outreach create policy and ranking risk and should not be part of PdfDukan’s plan.
- SEO and LLM visibility have no guaranteed shortcut. Helpful crawlable content, clear entities, evidence, citations, sound architecture, and external reputation increase eligibility—not certainty.

## Direct application to PdfDukan

The course supports the following audit order:

1. Confirm live crawlability, status codes, canonicals, robots directives, sitemap URLs, and indexable page inventory.
2. Map each PDF tool and informational intent to one primary URL to avoid duplicate targeting/cannibalization.
3. Create a dedicated, useful CamScanner-alternatives answer/comparison page if the current site does not satisfy that query.
4. Improve tool-page titles, headings, introductions, direct answers, FAQs only where genuinely useful, and contextual internal links.
5. Add verifiable trust/entity signals: clear ownership, About/contact/editorial information, privacy/security explanations, authors/reviewers, and update dates where appropriate.
6. Validate structured data against visible page content; do not add unsupported review, rating, or FAQ claims.
7. Test Core Web Vitals and real tool interactions, especially mobile document upload/processing flows.
8. Build links through useful tools, original research/guides, integrations, and editorial mentions—not purchased or automated spam.
9. Measure index coverage, non-branded queries, clicks, CTR, tool completion, return usage, and conversions in Search Console/analytics.
10. For LLM discovery, publish concise answer-first sections, comparison tables backed by evidence, stable URLs, clear entity facts, and sources that can be independently verified.
